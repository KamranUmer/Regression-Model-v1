# 📈 Linear Regression from Scratch

**Single-feature linear regression implemented with NumPy: model, cost and plots.**

## 📌 Overview

Implements the linear model f(x) = w·x + b by hand for a single-feature house-price example, computes predictions, and plots them against the training data. No ML library, just NumPy, to understand what happens under the hood.

## ✨ Features

- Model representation and predictions with NumPy
- Matplotlib plots of data vs. model
- Experiments in `main.py` and `test.py`

## 🚀 Getting Started

```bash
git clone https://github.com/KamranUmer/Regression-Model-v1.git
cd Regression-Model-v1
pip install numpy matplotlib
python main.py
```
